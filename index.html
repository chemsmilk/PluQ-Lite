    Phishing & URL Safety Tips

    Pause. Look closer. Make an informed choice.

    • Phishing is impersonation. Deceptive messages and sites try to get your passwords, money, or personal information.
    • Read the real destination. A familiar name before an @ can be login information. The hostname after it is the destination.
    • A lock is not a guarantee. HTTPS encrypts the connection. Deceptive websites can use it too.
    • Context matters. Check the sender and spelling. When unsure, use a known bookmark or type the official address yourself.
    • A URL is only one clue. These checks do not inspect content, reputation, redirects, downloads, or malware.

    About PluQ Lite

    PluQ Lite helps beginners understand a link before clicking. Four rule-based checks examine HTTPS, IP-address destinations, URL credentials, and unusually long URLs. Simple and Technical modes explain the same results with different wording.

    Built with HTML, CSS, and vanilla JavaScript. AI assisted development, planning, testing, and code explanation; no live AI model performs threat detection. The project supports the theme “Build with AI, Protect What Matters, Innovate with People at the Center.”

    No warning count proves a link safe or malicious. This tool does not visit websites or detect all phishing. If the event requires AI running inside the application, this version does not meet that additional requirement.
